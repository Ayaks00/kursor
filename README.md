# Лобачевский: Кривая Казань

Десктопная игра на **Electron**: окно приложения, собственная иконка, запуск без браузера и без сервера. Веб-версия заменена приложением.

## Запуск

Нужны Node.js 20+ и npm.

```
npm install
npm start
```

`npm install` скачивает бинарник Electron. Дальше игра открывается в отдельном окне.

## Сборка установщика

```
npm run build
```

Готовые файлы появятся в `release/`: установщик `.exe` и ZIP для Windows, `AppImage` и `tar.gz` для Linux. Для быстрой распаковки без установщика:

```
npm run pack
```

## Как я сделал приложение

Я взял готовую игру на чистом JavaScript и Canvas 2D и упаковал её в Electron. В `main.js` создаётся окно `BrowserWindow`, в него загружается `app/index.html`, системное меню убрано. Весь игровой код лежит в `app/`: `src/main.js` крутит кадры, `src/input.js` читает клавиатуру, `src/game.js` содержит физику и состояния, `src/levels.js` — уровни, `src/art.js` — спрайты, `src/ui.js` — текст поверх canvas, `src/audio.js` — звук.

Фишка — переключение геометрии: концы платформ интерполируются между обычным и кривым положением, «параллельные» навесы сходятся в идеальной точке и становятся мостами. Логический мир — 1920×1080, фоны встроены в `src/bg-data.js`, звуки — в `src/sfx-data.js`. Графика рисуется примитивами Canvas 2D, музыка синтезируется через Web Audio API, текст вынесен в DOM. Упаковку в десктопное приложение делает `electron-builder`.

## Управление

| Клавиши | Действие |
|---|---|
| `← →` / `A D` | движение |
| `Пробел` / `↑` / `W` | прыжок (выше при удержании); пока показана подсказка — скрыть её без прыжка |
| `Q` / `E` / `Shift` | переключить геометрию |
| `Esc` / `P` | пауза: продолжить, рестарт, звук |
| `R` | быстрый перезапуск уровня |
| `M` | звук вкл/выкл |
| `Enter` | старт, следующий уровень, подтверждение |

## Игра

1. **Улица Баумана** — обучение кривизне.
2. **Главное здание КФУ** — платформы в «двух листах» геометрии.
3. **Обсерватория Энгельгардта** — низкая гравитация.
4. **Казанский Кремль** — босс Зилант, три удара только в кривом режиме, затем катсцена и титры.

Есть чекпоинты, сохранение прогресса, счётчик чак-чака и индикатор геометрии.

## Файлы

- `main.js` — процесс Electron, создающий окно;

- `app/` — игра: HTML, CSS, JavaScript, картинки и звуки;
- `assets/icon.png` — иконка приложения;
- `release/` — готовые сборки после `npm run build`.
