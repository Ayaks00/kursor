# Лобачевский: Кривая Казань

Десктопная игра на **Electron**: окно приложения, собственная иконка, запуск без браузера и без сервера. Веб-версия заменена приложением.

## Запуск

Нужны Node.js 20+ и npm.

```
npm install
npm start
```

`npm install` скачивает бинарник Electron. Дальше игра открывается в отдельном окне.

## Сборка установщика

```
npm run build
```

Готовые файлы появятся в `release/`: установщик `.exe` и ZIP для Windows, `AppImage` и `tar.gz` для Linux. Для быстрой распаковки без установщика:

```
npm run pack
```

## Как я сделал приложение

Я взял готовую игру на чистом JavaScript и Canvas 2D и упаковал её в Electron. В `main.js` создаётся окно `BrowserWindow`, в него загружается `app/index.html`, системное меню убрано. Весь игровой код лежит в `app/`: `src/main.js` крутит кадры, `src/input.js` читает клавиатуру, `src/game.js` содержит физику и состояния, `src/levels.js` — уровни, `src/art.js` — спрайты, `src/ui.js` — текст поверх canvas, `src/audio.js` — звук.

Фоны уровней сверены с фотографиями реальных локаций и перерисованы в одном пиксельном стиле (см. источники ниже).

Фишка — переключение геометрии: концы платформ интерполируются между обычным и кривым положением, «параллельные» навесы сходятся в идеальной точке и становятся мостами. Логический мир — 1920×1080, все локации оформлены в одном детальном пиксельном стиле, фоны встроены в `src/bg-data.js`, звуки — в `src/sfx-data.js`. Графика рисуется примитивами Canvas 2D, музыка синтезируется через Web Audio API, текст вынесен в DOM. Упаковку в десктопное приложение делает `electron-builder`.

## Управление

| Клавиши | Действие |
|---|---|
| `← →` / `A D` | движение |
| `Пробел` / `↑` / `W` | прыжок (выше при удержании); пока показана подсказка — скрыть её без прыжка |
| `Q` / `E` / `Shift` | переключить геометрию |
| `F` | «Идеальная точка»: мгновенно собрать кривой мост и удержать его 2,6 с |
| `C` | «Гиперболический сдвиг»: рывок вперёд, сильнее в кривой плоскости |
| `Esc` / `P` | пауза: продолжить, рестарт, звук |
| `R` | быстрый перезапуск уровня |
| `M` | звук вкл/выкл |
| `Enter` | старт, следующий уровень, подтверждение |

## Игра

1. **Улица Баумана** — обучение кривизне: навесы собираются в мост только в кривой плоскости.
2. **Главное здание КФУ** — залы в «двух листах» геометрии, переключение прямо в прыжке.
3. **Обсерватория Энгельгардта** — низкая гравитация и орбиты, которые меняются вместе с плоскостью.
4. **Многоэтажное здание КФУ** — вертикальный подъём по «двойке»: плоские лестницы и кривые пандусы чередуются на каждом этаже, камера плавно следует за персонажем вверх, а на фоне — второй корпус университета. Чекпоинты привязаны к своей плоскости: после смерти игрок возвращается именно на тот этаж и в ту геометрию, где активировал флаг.
5. **Гостиный двор** — торговые аркады, где проходы существуют только в своей плоскости; нужно переключать геометрию между прилавками.
6. **Казанский Кремль** — финальный босс Зилант с 10 очками здоровья; удары наносятся только в кривом режиме, затем катсцена и титры.

После каждого из пяти обычных уровней показывается **мини-опрос** с вопросом об этом месте. За каждый правильный ответ Зилант теряет 1 очко здоровья ещё до начала боя: если ответить на все вопросы, на босса останется 5 очков. Неверный ответ ничего не отнимает, вопрос можно переиграть при повторном прохождении уровня.

В главном меню есть **выбор уровня** и **переключение языка** (`русский → english → татарча`); язык сохраняется между запусками. Открытые уровни можно переиграть, закрытые помечены и недоступны. В списке показываются рекорд времени и собранный чак-чак. Есть чекпоинты, сохранение прогресса и индикатор геометрии.

На уровнях появились движущиеся площадки, плиты, существующие лишь мгновение после переключения плоскости, и стражи, которые видны и опасны только в одном режиме. У Зиланта есть вторая фаза с дополнительной платформой и тремя огненными шарами. Музыка и звуки шагов различаются по локациям и материалам платформ.

Навыки построены на геометрии Лобачевского. **«Идеальная точка»** (`F`) мгновенно переводит мир в кривую геометрию и удерживает её 2,6 секунды — параллельные навесы сходятся и становятся мостом. Перезарядка 9 секунд. **«Гиперболический сдвиг»** (`C`) даёт короткий рывок вперёд; его дальность тем больше, чем выше кривизна. Перезарядка 5 секунд. Оба навыка отображаются в HUD и сбрасываются при смерти.

Текстуры и фон рисуются с выключенной интерполяцией и чётким масштабированием пикселей. Фон движется параллаксом медленнее камеры (около 16% от горизонтального смещения) и зацикливается через зеркальную копию, поэтому по мере прохождения уровня город тоже смещается, но без разрывов по краям. Статичные градиенты кэшируются, фоны предварительно загружаются, а DOM обновляется только при изменении значений. В скрытой вкладке симуляция останавливается, чтобы не копить задержку.
