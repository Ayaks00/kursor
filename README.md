# Лобачевский: Кривая Казань

Пиксельный веб-платформер: **меню → 3 уровня по Казани → босс Зилант → победа**.

**Играть онлайн:** https://ayaks00.github.io/kursor/  
**Команда:** команда ИБ

## Как я сделал игру и что использовал

Я написал игру на **чистом JavaScript, HTML5 Canvas 2D и Web Audio API** — без готового движка, сборщика и зависимостей. Каркас — `index.html` и `css/style.css`; `src/main.js` запускает `requestAnimationFrame` с фиксированным шагом 1/60 секунды. Ввод вынесен в `src/input.js`, звук — в `src/audio.js`, описания уровней — в `src/levels.js`, спрайты и эффекты — в `src/art.js`, физика и состояния — в `src/game.js`, интерфейс — в `src/ui.js`.

Уровни заданы данными: платформа — отрезок с обычными и «кривыми» концами плюс тип `both/flat/curve`. При загрузке я один раз умножаю координаты на `K = 4`, поэтому логический мир и raster совпадают — **1920×1080**. Фишка реализована через плавную интерполяцию концов платформ: `Q`/`Shift` меняет коэффициент кривизны, «параллельные» навесы сходятся в идеальной точке и становятся мостами. Без этого ни один уровень не проходится.

Четыре статичных фона 1920×1080 (Баумана, КФУ, обсерватория, Кремль) встроены в `src/bg-data.js` как data URI — игра открывается прямо с `file://`. Остальная графика рисуется примитивами Canvas 2D с внутренней сеткой 4 логических пикселя. Весь русский текст — настоящие HTML-элементы поверх canvas, на canvas рисуется только мир и эффекты. Музыку я синтезирую через Web Audio API; звуки прыжка, сбора, переключения и т. д. — готовые **CC0-сэмплы Kenney**, встроенные в `src/sfx-data.js`.

Проверял игру в Chrome и Яндекс Браузере, а также скриптами симуляции прохождения и проверки экранов. Размер исходной сборки — менее 400 КБ, загрузка быстрая, 30+ FPS.

## Идея

Казань — город, где создавалась неевклидова геометрия. Игрок — студент Казанского университета времени Лобачевского: бежит по Баумана, залам главного здания КФУ и обсерватории Энгельгардта, собирает чак-чак, а в финале сражается с Зилантом над Кремлём. Визуальный стиль — античный: мрамор, бронза, лавры, меандр, амфоры, колонны и звёздные карты.

### Механика кривизны

- `Q` / `Shift` переключает плоский и кривой миры.
- У «параллельных» платформ меняются концы: они сходятся в светящейся **идеальной точке**.
- В кривом режиме появляются мосты и пандусы, в плоском — обычные опоры.
- Переключать можно в прыжке; это обязательно для прохождения всех уровней.

Научная идея использована как игровая метафора, а не как исторический факт.

## Запуск

1. Откройте `index.html` в актуальном Chrome или Яндекс Браузере — двойным кликом, без сервера и без установки Node/Python.
2. Нажмите любую клавишу или кликните по экрану, чтобы включить звук.
3. Если масштаб страницы 50–70%, верните его на 100% — текст станет крупнее.

Запасная страница `play.html` помогает, если браузер держит старую версию из кэша. Необязательно: `python3 -m http.server 8080` и `http://localhost:8080`.

## Управление

| Клавиши | Действие |
|---|---|
| `← →` / `A D` | движение |
| `Пробел` / `↑` / `W` | прыжок (выше при удержании); пока показана подсказка — скрыть её без прыжка |
| `Q` / `E` / `Shift` | переключить геометрию |
| `Esc` / `P` | пауза: продолжить, рестарт, звук |
| `R` | быстрый перезапуск уровня |
| `M` | звук вкл/выкл |
| `Enter` | старт, следующий уровень, подтверждение |

Мышь работает в меню. На первом уровне есть скрываемая подсказка, в HUD — счётчик чак-чака и индикатор геометрии. Есть чекпоинты, возрождение и сохранение прогресса через `localStorage`.

## Уровни

1. **Улица Баумана** — первое знакомство с кривизной: навесы лавок сходятся в мост.
2. **Главное здание КФУ** — платформы в «двух листах» геометрии, переключение в воздухе.
3. **Обсерватория Энгельгардта** — низкая гравитация и звёздная навигация.
4. **Казанский Кремль** — босс Зилант: три попадания только в кривом режиме, затем катсцена и титры.
