# Шпора по процессу кодинга — от первого лица

Коротко: как я писал игру, что где лежит и что сказать, если спросят про реализацию. Для ответов про идею, историю и лицензии — `docs/qa-answers.md`.

## 1. Рассказ за минуту

«Я начал с веб-платформера на чистом JavaScript и Canvas 2D, а потом упаковал его в Electron. Точка входа десктопа — `main.js`: он создаёт `BrowserWindow` и грузит `app/index.html`. Внутри игры цикл крутится в `app/src/main.js`: `requestAnimationFrame`, накопитель времени и фиксированный шаг 1/60 с ограничением числа шагов подряд.

Ввод вынесен в `app/src/input.js`: клавиши превращаются в `down/pressed`, а `endFrame()` очищает нажатия после шага. Уровни описаны данными в `app/src/levels.js`: платформа — отрезок с двумя парами концов и типом `both/flat/curve/resonance/pulse`. При загрузке всё один раз умножается на `K = 4`, поэтому логика и raster совпадают — 1920×1080.

Движок в `app/src/game.js` — конечный автомат: меню, интро, игра, смерть, опрос, победа, пауза. Фишка — пара функций: `platformEnds()` интерполирует концы по кривизне, `platformSolid()` решает, материальна ли платформа. Навык «Идеальная точка» на короткое время делает оба типа дорог проходимыми через `idealActive()`.

Графику я рисую примитивами Canvas 2D в `app/src/art.js`: фоны, спрайты, частицы, эффекты, детализированного дракона и параллакс. Весь текст — DOM-слой: `app/index.html`, `app/src/ui.js`, `app/css/style.css`. Музыку синтезирую через Web Audio API в `app/src/audio.js`, звуки Kenney встроены как data URI в `app/src/sfx-data.js`. Фоны лежат в `app/assets/bg/*.png` и встроены в `app/src/bg-data.js`. Локализация RU/EN/TT — в `app/src/i18n.js`. В конце добавил презентации и документы по регламенту».

## 3. Кусочки кода, которые могу показать

**Кривизна и две дороги:**

```js
Game.prototype.idealActive = function () {
  return this.skills.ideal.lock > 0;
};

Game.prototype.platformSolid = function (plat) {
  if (plat.phase2 && (!this.boss || this.boss.hp > 2)) return false;
  if (plat.kind === 'pulse') return this.time - this.lastSwitchAt < 1.8;
  if (this.idealActive() &&
      (plat.kind === 'flat' || plat.kind === 'curve' || plat.kind === 'resonance')) return true;
  return plat.kind === 'both' ||
    (plat.kind === 'flat' && this.curvature < 0.5) ||
    (plat.kind === 'curve' && this.curvature >= 0.5);
};
```

**Навык:**

```js
if (inp.idealPressed() && sk.ideal.cd <= 0) {
  sk.ideal.cd = sk.ideal.cdMax;
  sk.ideal.lock = 2.6;
  this.target = 1;
  this.curvature = 1;
}
```

**Фиксированный шаг:**

```js
var STEP = 1 / 60;
while (acc >= STEP && guard < 6) {
  game.update(STEP);
  input.endFrame();
  acc -= STEP;
  guard++;
}
game.render();
```

## 4. Баги, которые ловил, — это и есть процесс

- **Страница иногда открывалась пустой из-за кэша:** добавил no-cache и вынес текст в DOM.
- **Текст на canvas читался плохо:** переписал интерфейс на HTML-элементы поверх canvas.
- **Уровень 4 не проходился после разнесения этажей:** разделил этажи на отдельные плоскости и переписал чекпоинты.
- **Чекпоинты на 4 уровне не совпадали с площадками:** поставил флаги на реальные точки приземления, увеличил зону активации и добавил 8 флагов с привязкой к плоскости.
- **Идеальная точка открывала только кривые дороги:** добавил `idealActive()` и одновременную активность плоских и кривых дорог.
- **Фон был статичным:** добавил параллакс, затем расширил его до 2D и направил движение в противоположную сторону от камеры.
- **Навыки были слева:** перенес основные клавиши на `K`/`L`, старые `F`/`C` оставил запасными.
- **Опрос был про саму игру:** заменил вопросы на научные о Лобачевском, параллаксе и кривизне.
- **Язык выбирался не сразу:** добавил стартовый экран выбора RU/EN/TT.

## 5. Если спросят про код

**Почему глобальный объект `KZ`?** — Нет сборщика: файлы подключаются тегами `<script>`, каждый модуль — IIFE и приклеивает свой объект к `KZ`. В консоли удобно смотреть `KZ.game`.

**Почему фиксированный шаг?** — Физика не зависит от частоты монитора: на 30, 60 и 144 Гц игрок движется одинаково.

**Почему платформы — данные?** — Можно править уровни, не трогая движок: один массив в `levels.js`, общие коллизии и движение.

**Как проверял проходимость?** — Симуляции всех уровней и босса, отдельные тесты навыков, языка, опроса, чекпоинтов, параллакса, fuzz и рендер. Ошибок нет.

**Что сложнее всего?** — Сделать кривизну одновременно понятной и полезной: платформа существует только в своей плоскости, переключаться нужно в прыжке, а навык должен на короткое время снимать это ограничение, не ломая уровень.
